# Применение ИИ

При создании любого материала (см. список ниже) обязательно нужно указывать, что этот материал создан с помощью ИИ, а также какая именно модель ИИ была применена. Примеры, где это должно быть указано:

* описание коммита - название модели ИИ в начале описания коммита;
* код коммита - в начале описания коммита;
* часть кода в коммите - комментарий в начале сгенерированной части кода;
* текст комментария в code review - перед текстом ответа модели ИИ (см. подробнее ниже);
* code review в целом - в начале каждого комментария, созданного моделью ИИ.

Должна быть чётко определена граница ответственности за материал между человеком и моделью ИИ.
Нельзя применять материалы, полученные через ИИ, без тщательной проверки со стороны одного или
нескольких компетентых специалистов. Материалы, полученные через ИИ, требуют более тщательную
проверку из-за горазо меньших способностей ИИ понимать контекст решения, валидировать решение
с т.з. корректности его применения в предметной области, а также поддерживать уровень качества
программного кода, приемлемый для изучения и доработки компетентыми специалистами.

В конечном итоге, автор материала несёт ответственность за то, что он взял у модели ИИ и внёс
в программный продукт.

Сообщения в рамках code review должны быть осмысленными и составленными их авторами, даже если эти
авторы ссылаются на ответы моделей ИИ. Автор сообщения, содержащего ответ модели ИИ, обязан в этом
же сообщении однозначно отделить ответ модели ИИ от своей части сообщения, например, с помощью блока
цитаты и с указанием названия модели ИИ, и описать своё отношение (согласие, не согласие)
с содержанием ответа модели ИИ.

    Эти рекомендации составлены на основе документа "AI Usage Policy" в ESLint 10.
    См. docs/src/contribute/ai-policy.md
